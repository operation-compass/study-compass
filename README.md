# Study COMPASS α v0.2

スマホで短く学習し、方式別の記録から復習するα版です。

## 実装
- 社会の○×、社会用語・英単語の自力再生
- 紙に書いた後の書字自己採点、紙なしの再生への切替
- 回答数・正解数・自動正答率・自己採点○△×の分離
- 7日推移、教科・スキル・期間フィルタ、単元状態
- 遅延復習改善、二重送信防止、復習0件の明示
- 端末保存・エクスポート・削除、日本時間の日付

## 教材と記録
教材は既存α版のCHECK相当のデモを継承しています。確認済み教材の正式公開とは区別します。旧版の保存領域は変更せず、v0.2の記録はstudyCompassAlphaV2に保存します。方式・日時が不足する旧集計は新しい分析に混ぜません。

## 未実装

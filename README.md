# Study COMPASS α v0.3

高校受験向けの5教科学習デモ。4択を中心に、自動採点・即時解説・復習候補・学習記録に対応しています。

## 数学
- 300問収録
- 基礎 125問 / 標準 140問 / 入試実戦 35問
- 6分野: 数と式 / 方程式 / 関数 / 図形 / データ / 確率
- 福岡入試を意識した大問チャレンジ 17セット
- 今日の10問: 基礎4 + 標準4 + 入試実戦2
- 単元別・難易度別の出題に対応

## 学習機能
- 4択の自動採点
- 回答直後の解説
- 間違い・あとで解く問題の復習
- 7日 / 30日の学習集計
- フラッシュカード / 問題だけ確認
- ブラウザ内の学習履歴保存

テーマ: 学習コンパス。深いネイビー、温かい白、ミントを基調に、スマホで1問ずつ集中できるUIを優先しています。

教材は確認中です。4択の結果だけで、数学の途中式・記述力・入試得点そのものを判定したとは表示しません。

# 2026-10-18 自動監査・公開の原因調査

調査方法：GitHubコネクタで現行mainのセレクタ・証拠検証・提案・公開・配信ワークフローを直接取得。GAS保存ソースと旧監査方針はfeature/drive-approval-gate-20261016から取得。定期監査09:20報告と設定画面の一時停止状態を照合。正本の今回再読・稼働中GASとのコード再照合・拒否されたツール出力原文の取得は未実施。

## 確認できた原因・不足

1. **監査実行機構が未接続**。mainの scripts/run-independent-content-audits.cjs と .github/workflows/verify-content-audit-runner.yml は取得時404。ローカルの同ランナーはAPI接続必須の導入前案で、出力はtechnical=PENDING・常にHOLD。現行公開ワークフローは既存証拠の検証を行うだけで、独立監査者を起動しない。クラウドタスクで独立した3実行が可能かは未確認。プロンプトで独立実行を要求しても、その実行機構を実装したことにはならない。
2. **運用ルールの配布先が分裂**。mainのAGENTS.mdは取得時404、mainのdocs/audited-sheet-to-web.mdにはローカルに追加した停止防止・更新後スケジュール状態の説明がない。作業ブランチのaudits/three-stage-publishing-policy.mdには依然「Do not automatically merge until...」「initial rollout ... recovery verification」等の旧導入段階記述がある。ローカル文書更新はクラウドから参照できる正規のルール更新とは別。
3. **書き込み拒否の根拠が欠落**。09:20報告はGitHub証拠保存とSheetsログ保存の安全チェック拒否を述べるが、実際の操作引数・拒否原文・必要承認を記録していない。接続権限不足、実行環境制約、操作内容への拒否のどれかは特定できない。安全チェックを迂回して再試行してはならない。
4. **正本データと独立監査が未完了**。09:20報告ではGAP10-6〜10が学年「中1〜中3」、9は既存問題と意味重複。現行セレクタとGAS保存ソースの学年条件は /^中[123]$/ で一致しているため、これはセレクタだけの問題ではない。正本を再読して学習内容に基づき修正し、新SHAで全役割を再監査する。現在3PASSゼロという事実だけでも公開不可。

## コードから確認した運用上の別の弱点（09:20停止の直接原因とは未確定）

5. **PRのCI完了待機が公開制御コードにない**。scripts/auto-publish-ready.cjsは同じ処理内で静的3検査・証拠照合・差分再生成を実行するが、PRのcheck-runs/status成功を確認する処理を経ずmerge APIへ進む。配信と3モードDOM検査はマージ後。従って「PR CIすべて成功してからマージ」がコード単体で保証されているとは言えない。リポジトリ側の必須チェック設定は今回未確認。
6. **証拠修正のみでは公開処理が再起動しない**。提案ワークフローのpush対象はstaging bundleの変更のみ。GAS保存ソースは同内容のbundleを12時間未満では書き直さない。証拠不足などで一度失敗した後、docs/auditsだけ修正してもpush条件に入らず、次のGAS実行でも内容が同じなら起動しない。再開は既存workflow_dispatch等の明示的な再実行、または正規同期での変更・12時間後の更新が必要となる可能性がある。自動監査タスクの再開とは別問題。
7. **検証の範囲が名称から分かりにくい**。配信CIは3モードのDOM起動を確認するが、各新規問題について実クリック採点・スマホ実画面・既存学習履歴継続をすべて自動実証する内容ではない。別の独立技術監査が必要。mainの内容一致や628問という件数は、Cloudflare上の新規問題の採点実測と同義ではない。

## 修復順序

1. 拒否された2操作の原文と実行環境で利用可能なツールを取得し、書き込みと独立監査実行の成立条件を特定する。権限を推測で拡張しない。
2. 実際に参照可能なGitHub/クラウドの運用方針を揃える。ローカルだけの更新を反映完了と報告しない。
3. 正本の学年・重複を修正して版/SHAを固定し、独立3監査と証拠保存を1バッチで実証する。内容監査接続のない状態を「無料無人監査完成」と呼ばない。
4. PR検査完了の扱いと、証拠修正後の再実行手順をコード・運用で明確化してから、既存定期実行を再開する。新規タスクやGASトリガーは作らない。

今回は調査記録のみ。main・正本・稼働中GAS・権限・公開設定を変更していない。

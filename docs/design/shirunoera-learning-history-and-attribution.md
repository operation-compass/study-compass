# SHIRUNOERA Web｜学習記録・流入解析・解説動画 実装仕様（検証用）
更新日: 2026-11-23

## 1. 学習記録
- 実際の問題演習で回答を確定した時だけ `ShirunoeraLearning.recordAnswer({questionId,subject,major,minor,correct})` を呼ぶ。現時点の検証用ページには問題演習がなく、呼出しは未接続。
- 学習記録は閲覧端末の localStorage `shirunoera.learning.v1` に保存。記録の主キーは公認の `question_id`。古いStudy COMPASSの履歴を勝手に置換・破棄しない。
- 5教科レーダーは **履修カバー率**＝ユニーク解答済み問題数／教科別公開問題数。正答率を別指標として見せる。未学習は値0の評価ではなく「未学習」と明記。
- 正答率は現行試作では問題IDごとの**直近正誤**で集計。再解答・初回解答の差異を将来別表示できるよう回答回数も記録。記録がない間は `—`。
- 単元別弱点は「記録5問以上」の単元を正答率昇順で表示。1問のみ正解・不正解で苦手判断しない。1問あたりの回答数カウントと解答済みID数を区別する。
- スマホでは五角形と苦手単元を縦積み。レーダー単独で判読できない場合に備えてテキストラベルを併記。
- 端末変更、プライベートブラウザ、ブラウザ削除時は履歴引き継ぎ不可。データ保全・消去・エクスポートは将来仕様に含める。

## 2. アクセス元の解析
**現時点で集計トラッキングは未導入。** GitHubの検証ページに新規の第三者トラッカー、Cookie、収集先を追加していない。
本番公開時に、Cloudflare Web Analytics等のプライバシーに配慮したサイト全体分析を検討する。計測する対象は日別PV、ユニーク訪問の概数、ランディングページ、参照元ドメイン、デバイス種別。正確なユニーク人数は識別制約により得られない場合がある。
投稿リンクにはチャネルを示すUTMを付ける例:
- `?utm_source=instagram&utm_medium=social&utm_campaign=history_quiz`
- `?utm_source=tiktok&utm_medium=social&utm_campaign=history_quiz`
- `?utm_source=youtube&utm_medium=social&utm_campaign=history_quiz`
- `?utm_source=x&utm_medium=social&utm_campaign=history_quiz`
計測先が確定し、プライバシー告知・データ保持方針を整備するまで、UTMを勝手に端末識別情報・学習結果と結合しない。IP、氏名、アカウント情報、個人別訪問履歴や位置情報を取得しない。
`document.referrer` はアプリ内ブラウザ・ブラウザのポリシー・直接流入で欠落しうる。UTMがない流入は「直接／不明」として表示する。**アクセス元は推定であり確実な個人追跡ではない**。クリックイベント計測は本人の同意要否等を確認してから適用。

## 3. 単元別解説動画
学習階層の `subject / unit_major / unit_minor` をキーとし、動画マスタは今後以下の表とする:
`video_id, subject, unit_major, unit_minor, title, provider, canonical_url, duration_seconds, publish_status, last_verified_at`
公開済みの動画のみリンク表示。準備中は「動画は準備中」。空の埋め込みiframeを表示しない。動画の利用者追跡を増やさないため、埋め込みよりもクリックしてYouTubeを開くリンクを優先。制作時に動画追加ができるよう問題データと動画データを分離。
動画公開後には、(1) 教科・単元設定画面 (2) 問題の解説画面 (3) 苦手単元のリストから同じ動画にたどり着けるようにする。

## 4. 本番導入前の必須ゲート
1. 学習画面と本番CSVの対応を検証し、正答判定後のみ履歴を更新。解答前・画面離脱時に正誤を捏造しない。
2. ラベル「履修カバー率」と「正答率」を分離。未学習は—として表記。
3. 公開問題の追加・削除で分母変動する場合は、その旨を説明し日付基準の整合性を保つ。
4. スマホの5教科タブ、グラフ、動画欄について実ブラウザでテスト。
5. アクセス解析は導入前に計測先の仕様とプライバシー告知を承認し、既存本番設定を安全に保全する。
6. 既存559問・Google Sheets・Cloudflare本番ルート・定期タスクをこのドラフトPRの作業で変更しない。

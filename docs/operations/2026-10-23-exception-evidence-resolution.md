# Study COMPASS｜実GAS例外判定後の証拠充足ルール（2026-10-23）

## 検証済み
- ユーザー実GAS出力：SC-SOC-HIS-WEB26-000001〜000003、技術事前検査3/3 PASS、正本SHA-v2一致、公開0、HOLD。
- GAS `studyPreviewThreeCoinsExceptionsReadOnly` は6種の例外のうち、出典実内容、意味重複、本番Web、学習品質、実機採点・履歴、公開承認について、外部証拠を取り込む入力を持たず**常に固定例外**として返す。したがって再実行しても解消できない。プログラムの「未確認」は「不合格」と同義ではない。
- 現在、公開サイト `https://study-compass.occompass-info.workers.dev` は今回の外部取得環境からアクセス不可。GitHub main の `index.html` と `legacy-study.html` は取得メタデータのみで本文が空。したがって公開済みID不在・重複なしは**未検証**。存在しないものと扱わない。

## 証拠充足の仕様（今後の実装に必要）
- 出典内容：閲覧可能な一次・公的本文の引用位置、URL、照合時刻、対象ID＋v2 SHA、検証者または実行IDを記録する。リンクがあるだけでは自動PASSしない。
- 品質：正本MASTER全件の意味類似検索と、実配信のSOCIALリスト双方への一致・近似比較。類題は例外、事実確認だけで解除しない。
- 技術：本番と同等の隔離プレビューで画面・正誤採点・既存学習履歴非破壊を確認。現行のプレフライトはデータ形式の確認であってこの要件の代替ではない。
- 監査記録：単なる候補本文に自動PASSを追記せず、証拠の実バイトSHA、出典、対象版を紐付けた別管理の記録を作る。
- 公開権限：監査方針の採用は特定問題のリリース承認ではない。正本のCHECK/FALSE、旧HOLD・禁止注記、認証済み委任/承認を別ソースから検証する。既存旧READYを自動昇格しない。
- 例外解消は証拠が揃った種別だけに限定し、未確認はそのままHOLD。問題データの改変・GASトリガー変更・mainへの自動マージはしない。

## 次の実装単位
読み取り専用の「証拠を受け取って例外を再評価する」処理を影響のない開発ブランチで構築し、実際に出典/重複/配信データを取れるコネクタを接続する。認証済み権限がない間はrelease_authorized=false固定。
